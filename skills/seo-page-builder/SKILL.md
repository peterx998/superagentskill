# SEO Page Builder

## Goal

Create a safe, conversion-oriented, SEO/GEO-friendly page plan and implementation path.

## Inputs

- Page topic or target keyword
- Target funnel stage
- Related product or CTA
- Existing page docs if any

## Required sections

1. Search intent summary
2. H1 and hero subtitle
3. Above-the-fold CTA
4. Problem/concern section
5. Method or routine section
6. Comparison or checklist section if useful
7. FAQ section
8. Final CTA
9. Meta title and meta description
10. Internal links
11. Compliance review

## Dr. Pen page patterns

Use these page types when relevant:

- Clean Confidence
- Skin Renewal
- Gentle Aftercare
- Texture Care
- Targeted Care
- Verify Authenticity
- Pen vs Roller
- Cartridge Guide

## Compliance rules

Avoid medical claims and guaranteed outcomes. Use appearance and routine language.

## Output

Create these files where appropriate:

- `docs/agents/prds/YYYY-MM-DD-seo-<slug>.md`
- `docs/agents/issues/seo-<slug>/ISSUE-01-page-content-structure.md`
- Optional Shopify metafield/metaobject draft in `docs/agents/reports/<slug>-metaobjects.md`

End with a short implementation checklist.
