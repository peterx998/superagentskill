# Operator Handoff

## Goal

Make it easy for the next person or next Codex session to continue without losing context.

## Include

1. Task objective
2. What changed
3. Files changed
4. Commands run
5. Verification results
6. Known risks
7. Rollback steps
8. Follow-up issues
9. Business/operator notes

## Save path

Use:

```txt
docs/agents/handoffs/YYYY-MM-DD-<slug>.md
```

## Output

- Handoff file path
- 5-line summary for the user
